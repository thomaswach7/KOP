# Creo-MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Python-MCP-Server, der Creo Parametric 12 über CREOSON (+ Mapkeys, optional VB-API) steuert, inkl. Modellbaum.

**Architecture:** `creo_mcp` (MCPServer, stdio) → async `CreosonClient` (HTTP/JSON) → CREOSON → Creo. Die 175 CREOSON-
Funktionsspezifikationen liegen als Paketdaten bei und treiben Prüfung, Hilfe und den generischen Aufruf. Ein stdlib-HTTP-Mock
simuliert CREOSON für Tests/Demo.

**Tech Stack:** Python ≥3.10, `mcp` 2.3 (`from mcp.server.mcpserver import MCPServer`), `httpx`, `pydantic`, pytest(+asyncio); optional `pywin32`.

**Spec:** `docs/superpowers/specs/2026-11-23-creo-mcp-design.md`

## Global Constraints

- Ordner `Creo_MCP/`, Paket `src/creo_mcp`, Einstieg `python -m creo_mcp` und Script `creo-mcp`.
- Werkzeugnamen `creo_<verb>_<objekt>`, snake_case; jede Funktion mit `ToolAnnotations` (read_only/destructive/idempotent/open_world).
- Env: `CREOSON_URL` (Default `http://localhost:9056/creoson`), `CREO_VERSION` (Default `12`), `CREO_MCP_TIMEOUT` (Default `120`),
  `CREO_MCP_READ_ONLY`, `CREO_MCP_ALLOW_DANGEROUS`, `CREO_MCP_ALLOW_SYSTEM_MAPKEYS` (Default aus), `CREO_START_DIR`, `CREO_START_COMMAND` (Default `nitro_proe_remote.bat`).
- Nach jedem neuen CREOSON-Sitzungsaufbau: `creo.set_creo_version {"version": CREO_VERSION}`.
- Mapkeys mit `@SYSTEM` werden abgelehnt, solange `CREO_MCP_ALLOW_SYSTEM_MAPKEYS` aus ist.
- Modellbaum: Default `max_nodes=400`; Listen-Default `limit=100`.
- Keine Ausgabe auf stdout außer MCP-Protokoll (Logging nach stderr).

## Review Focus

1. CREOSON nicht gestartet (Connection refused) → Fehlermeldung nennt CREOSON-Start und `creo_doctor` (Task 3).
2. CREOSON neu gestartet (Sitzung ungültig) → genau ein automatischer Reconnect + Wiederholung (Task 3).
3. Umlaute in KE-/Parameternamen ("Grundkörper") → UTF-8 unverändert hin und zurück (Task 2/6).
4. Große Baugruppe → Baum wird bei `max_nodes` abgeschnitten, mit Hinweis statt Kontextflut (Task 5).
5. Mapkey mit `mapkey(continued)`-Zeilen → wird gemäß CREOSON-Hinweis zu einer Zeile normalisiert (Task 4).
